# دسترسی قابل انتخاب برای کارکنان سرور

مالک سامانه از «کاربران ← ویرایش کاربر ← تعیین دسترسی‌های کارمند» مجوزها را با تیک تعیین می‌کند. ابتدا در «نقش‌ها و عضویت‌ها» یک عضویت فعال با نقش کارمند سامانه و بدون شرکت ایجاد کنید. حساب کارمند نباید Superuser باشد. حساب مالک همیشه اختیار کامل دارد؛ برای کار محدود، حساب کارمند جدا بسازید.

مجوزها شامل مشاهده/مدیریت دستگاه‌ها، منابع، قیمت‌ها، پیام‌ها، شرکت‌ها و قالب‌ها، مشاهده/ایجاد/ویرایش کاربران عادی، مشاهده/بارگذاری Firmware، پایش/بررسی سرویس‌ها و مدیریت پلن‌ها، ارتباطات، توکن‌ها و تنظیمات است. مجوز نوشتن، مشاهده همان بخش را هم می‌دهد؛ مثلاً افزودن کاربر اجازه ویرایش او را نمی‌دهد. مجوزها در سطح کل سامانه هستند، نه فقط یک شرکت. مشاهده جزئیات گجت شامل محتوای انتخابی و سوابق بازر آن هم هست؛ مدیریت گجت شامل تنظیمات و قوانین بازر است.

تغییر عضویت‌ها، تعیین مجوزها، صدور توکن اولیه دستگاه و چرخش رمز MQTT فقط برای مالک باقی می‌ماند. کارمند دارای مجوز ویرایش کاربر نمی‌تواند حساب مدیر یا کارمند دیگر، حتی غیرفعال، را تغییر دهد یا رمز آن را عوض کند. Django admin برای حساب‌های غیرمالک بسته است تا راه دورزدن مجوزهای پنل نباشد. مجوز مدیریت توکن‌ها و تنظیمات ارتباطی حساس است؛ فقط به کارمند مورد اعتماد بدهید.

کارمند بدون مجوز فقط میز کار خالی دارد؛ داشبورد کلی مدیر را نمی‌بیند. منوها و عملیات غیرمجاز مخفی‌اند، درخواست مستقیم GET/POST با 403 رد می‌شود و لغو مجوز در درخواست بعدی اعمال می‌شود. جریان SSE نیز مجوز را در طول اتصال بازبینی می‌کند. تغییر هر مجوز در لاگ مدیریت ثبت می‌شود. نقش‌های کاربران شخصی و شرکتی و سهمیه پلن‌ها تغییر نمی‌کنند.

## ارتقا روی نصب guided

ابتدا پشتیبان دیتابیس، runtime (کلید رمزگذاری) و فایل .env.guided را تهیه کنید. migration 0014 فقط جدول مجوزها را اضافه می‌کند؛ داده‌های قبلی را حذف نمی‌کند. **کارمندان فعلی پس از ارتقا دسترسی پیش‌فرض ندارند** و مالک باید تیک‌های لازم را تعیین کند. مالک و Superuser دسترسی خود را حفظ می‌کنند.

در پوشه پروژه و روی شاخه feature/price-platform-panels:

```bash
git pull --ff-only origin feature/price-platform-panels
sudo docker compose --env-file .env.guided -f docker-compose.guided.yml --profile public build
sudo docker compose --env-file .env.guided -f docker-compose.guided.yml --profile public stop api worker beat collector broker_config
sudo make guided
```

entrypoint سرویس API migration را اجرا می‌کند و سپس سایر سرویس‌های برنامه بالا می‌آیند. این ارتقا وقفه کوتاه دارد. نام پوشه/پروژه و فایل .env.guided قبلی را نگه دارید؛ down -v اجرا نکنید. اگر build شکست خورد، مرحله توقف را اجرا نکنید. اگر راه‌اندازی خطا داد، لاگ api را بررسی کنید.

پیش‌نمایش بدون ارسال فرم: docs/previews/staff-access.html، تولیدشده از قالب واقعی با داده آزمایشی. آزمون‌های خودکار SQLite جای آزمون استقرار واقعی را نمی‌گیرند.
