# 14) پنل کنترلی سرور

## هدف
همه اطلاعات مهم را از داخل Django Admin ببینی و موارد قابل‌ویرایش را مستقیم تغییر بدهی.

## مسیر دسترسی

- `http://localhost:8000/admin/`

## چه چیزهایی قابل مشاهده و ویرایش هستند

### دستگاه‌ها
- نام دستگاه
- پلن
- فعال/غیرفعال
- نسخه UI
- config نهایی

### پروفایل دستگاه
- تم
- رنگ‌ها
- layout
- interval به‌روزرسانی
- config سفارشی و نهایی

### منابع داده
- نام
- label
- فعال/غیرفعال
- key

### خط‌مشی پلن
- اینکه پلن اجازه سفارشی‌سازی دارد یا نه
- محدودیت تعداد page و element

### قالب‌های UI
- template
- pageها
- elementها

### رویدادهای sync و اعلان‌ها
- فقط برای مشاهده و audit
- برای تشخیص خطا و تغییرات

## مزیت این پنل

- نیاز به ساخت پنل سفارشی پیچیده از همان اول ندارد
- سریع و پایدار است
- برای تیم فنی و مدیریت داخلی کافی است
- بعداً می‌توان یک داشبورد اختصاصی هم روی همین دیتا ساخت
