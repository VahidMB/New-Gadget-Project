# پیش‌نمایش پنل‌ها

این فایل‌ها خروجی قالب‌های واقعی Django با داده‌های ساختگی پروفایل demo هستند. ارتباط زنده، ارسال فرم و لینک‌های عملیاتی برای بررسی امن ظاهر غیرفعال شده‌اند؛ تغییر حالت روشن/تاریک و باز کردن منوی موبایل فعال است.

- `personal.html`: پنل شخصی و قیمت‌ها
- `company.html`: پنل شرکت و انتخاب دستگاه
- `admin.html`: داشبورد مدیر
- `monitoring.html`: پایش سرویس‌ها؛ نبود اندازه‌گیری با مقدار نامشخص نشان داده می‌شود

بازسازی با `python scripts/export_panel_previews.py` بعد از راه‌اندازی demo انجام می‌شود. نمونه قیمت‌ها نرخ واقعی بازار نیستند.

## وضعیت بررسی

- ۱۲۰ تست خودکار روی SQLite عبور کرده‌اند.
- Ruff، بررسی Django، نبود migration جاافتاده و `git diff --check` عبور کرده‌اند.
- تست‌ها شامل اصلاح نمایش پنل در نبود نمونه مصرف منابع و جلوگیری از تخصیص زودهنگام لیست قیمت زمان‌بندی‌شده هستند.
- دانلود مرورگر در محیط بررسی فایل معتبر برنگرداند؛ اسکرین‌شات مرورگر و بررسی تصویری دسکتاپ/موبایل هنوز انجام نشده است. این فایل‌ها اسکرین‌شات نیستند.
- Docker/PostgreSQL واقعی، MQTT واقعی، منابع خارجی واقعی، افزونه WordPress و نصب روی ESP32 در این محیط تأیید نشده‌اند.
- ساخت ربات تعاملی تلگرام به مرحله بعد تعلق دارد؛ endpoint دریافت و قرارداد آن آماده است.

قبل از انتشار عمومی، موارد انجام‌نشده بالا باید روی محیط مقصد تأیید شوند. راهنمای کامل در `docs/bootstrap/19-live-buzzer-connections.md` است.

فرم‌های جدید با `--settings-panels` بازسازی می‌شوند: `buzzer.html` برای قوانین بازر، `sources-settings.html` برای منابع، `connections.html` برای ارتباطات و `integration-settings.html` برای اعتبارنامه‌ها.

`staff-access.html`: انتخاب تیکی مجوزهای کارمند؛ بازسازی با `--staff-access`. راهنمای ارتقا: `docs/bootstrap/20-staff-permissions.md`.
